# Архитектура backend части приложения

## 1. Общая концепция

Приложение представляет собой веб-интерфейс для упрощения работы с вычислительным кластером на базе SLURM. Основная цель - абстрагировать пользователя от сложности прямого взаимодействия с SLURM командами через терминал.

### 1.1 Основные возможности
- Отправка задач в кластер через удобный веб-интерфейс
- Мониторинг состояния задач
- Управление очередью задач
- Просмотр результатов вычислений
- Управление файлами (загрузка входных данных, скачивание результатов)

## 2. Технологический стек

| Компонент | Технология | Назначение |
|-----------|-------|------------|
| Backend | Java 17+ | Основная логика приложения |
| Framework | Spring Boot 3.x | Создание REST API |
| Сборка | Maven | Управление зависимостями |
| Взаимодействие с SLURM | slurmrestd | REST API для управления SLURM |
| Аутентификация | Spring Security + JWT | Безопасность |
| Документация API | SpringDoc OpenAPI (Swagger) | Документирование эндпоинтов |
